**Personal Portfolio Website**

This project is a responsive personal portfolio website developed using HTML5 and CSS3. It showcases my introduction, technical skills, projects, experience, certifications, achievements, and contact information in a structured and user-friendly layout. CSS Flexbox, Grid, media queries, and interactive hover and focus styles are used to improve the design and responsiveness across desktop and mobile devices. The website demonstrates my frontend development skills and provides a central place to explore my work and contact me.
